# Сравнительный анализ алгоритмических дескрипторов ORB, AKAZE, HOG, LBP для задач видеоаналитики реального времени
Цель: экспериментально сравнить ORB, AKAZE, HOG и LBP по скорости обработки, вычислительной нагрузке и качеству извлекаемых признаков при анализе видеопотока.
Основной вопрос исследования: какой из четырёх дескрипторов лучше подходит для видеоаналитики в реальном времени с учётом компромисса между скоростью и качеством?
