# Сравнительный анализ алгоритмических дескрипторов ORB, AKAZE, HOG, LBP для задач видеоаналитики реального времени
Цель: экспериментально сравнить ORB, AKAZE, HOG и LBP по скорости обработки, вычислительной нагрузке и качеству извлекаемых признаков при анализе видеопотока.
Основной вопрос исследования: какой из четырёх дескрипторов лучше подходит для видеоаналитики в реальном времени с учётом компромисса между скоростью и качеством?

Задачи:
- Захватывать видео с веб-камеры или файла
- Применять выбранный алгоритм к каждому кадру
- Визуализировать результаты обработки
- Измерять время обработки кадра, FPS и другие показатели
- Сохранять результаты экспериментов в CSV
- Строить сравнительные графики и формировать итоговый отчет

Объекты сравнения:
ORB - Oriented FAST and Rotated BRIEF
Находит характерные точки и описывает их бинарными признаками. Подходит для быстрого поиска совпадений между кадрами и отслеживания объектов.

AKAZE
Выявляет локальные особенности изображения в нелинейном масштабе. Интересен для сравнения устойчивости признаков при изменении масштаба и освещения.

HOG - Histogram of Oriented Gradients
Описывает распределение направлений градиентов. Подходит для анализа контуров и формы объектов, например пешеходов.

LBP - Local Binary Patterns
Кодирует локальные изменения яркости и описывает текстуру.
